# Company handover

## Review scope

This is Ghaith's alpha website concept for Furnishing Packs. Review the presentation of the furniture ranges, pack selection, configuration, quote journey and catalogue. The application source is the supplied photo based `furnishing-packs-rooms` version.

The 3D room/furniture model was removed because its added loading delay was not justified by its usefulness for the alpha. The current experience uses room and product photographs. Its WebGL hero effect transitions between flat photographs and does not introduce a 3D model.

The earlier 3D and alternative site experiments, local Claude configuration and design-tool caches are excluded from the repository package.

## Sharing the alpha

Repository: <https://github.com/Syghx/furnishing-packs-alpha>.

The repository is **public**, so reviewers can open the link and download the ZIP without signing in or creating a GitHub account. GitHub displays the source files; it does **not** automatically run the website. Follow the [README](../README.md) to preview the site and the logo page locally.

Anyone on the internet can also view or copy the public files. This is a review prototype, not a live customer site.

## Feedback to collect

- Are the correct ranges, product images and customer sectors represented?
- Is the price and bedroom configuration clear?
- Is it easy to inspect a room and understand a pack's contents?
- Can a reviewer add a pack, change quantities and follow the quote totals?
- Does the delivery-week selection make sense as a preference?
- Is the mobile layout clear and comfortable to use?
- What information or integrations should the next version prioritise?
